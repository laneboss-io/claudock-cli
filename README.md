# claudock-cli

The Claudock command line in Go: run Claude Code under one of several profiles, read each profile's usage and
pick the one with room left. One static binary for macOS and Linux.

**Status: being ported.** The working CLI today is the Swift one in
[laneboss-io/claudock](https://github.com/laneboss-io/claudock). This repository replaces it command by command,
each command proven by black-box tests that run the built binary.
